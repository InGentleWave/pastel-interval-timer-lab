# 타바타 타이머

iPhone과 PC 브라우저에서 같이 쓰는 인터벌 타이머 웹앱입니다. 서버 없이 GitHub Pages에서 동작하며 외부 라이브러리를 쓰지 않습니다.

## 안내

- 이 프로젝트는 특정 상용 타이머 앱과 관계가 없으며, 개인 학습 목적으로 코드를 직접 작성했습니다.
- 사용자 데이터를 수집하거나 외부로 전송하지 않습니다. 설정과 기록은 사용하는 기기의 브라우저에만 저장됩니다.
- 같은 안내가 앱 첫 화면(처음 한 번)과 설정 화면의 '앱 정보'에도 표시됩니다.

## 기능

- 타바타: 준비 · 운동 · 휴식 × 라운드, 사이클 반복과 사이클 간 휴식
- 라운드: 준비 · 운동 · 휴식 × 라운드
- 스톱워치: 시작 · 정지 · 랩 · 초기화
- 알림 선택: 비프음(전환 3초 전부터 1초마다 짧은 음, 전환 시 긴 음) 또는 한국어 음성 안내
- 프리셋: 모드별로 이름을 붙여 여러 개 저장, 불러오기, 덮어쓰기, 이름 변경, 삭제 (기기 브라우저에 저장)
- 화면 켜짐 유지, 오프라인 실행, iPhone 홈 화면 설치
- PC 단축키: Space 시작/일시정지, R 초기화, L 랩, 1·2·3 탭 이동, Esc 설정 닫기

## 진행 규칙 (타바타)

- 사이클 안에서는 운동 → 휴식을 반복합니다.
- 사이클의 마지막 라운드 뒤에는 일반 휴식 대신 사이클 간 휴식이 들어갑니다.
- 마지막 운동이 끝나면 바로 종료합니다.
- 0초로 설정한 단계는 건너뜁니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| index.html | 화면과 타이머 동작 전체 |
| manifest.webmanifest | 홈 화면 설치 정보 (이름, 아이콘, 색) |
| sw.js | 오프라인 실행용 서비스 워커 |
| icon-192.png, icon-512.png | 앱 아이콘 |
| apple-touch-icon.png | iPhone 홈 화면 아이콘 |

## 배포 (GitHub 웹 화면 기준)

1. 공개(Public) 레포를 새로 만듭니다. 무료 계정은 공개 레포에서만 Pages를 쓸 수 있습니다.
2. 레포 첫 화면의 uploading an existing file 링크(파일이 이미 있는 레포라면 Add file → Upload files)로 이 폴더의 파일 7개를 모두 올리고 Commit changes를 누릅니다. 파일은 레포 최상위에 있어야 합니다.
3. Settings → Pages → Build and deployment에서 Source를 Deploy from a branch로, Branch를 main과 /(root)로 고르고 Save를 누릅니다.
4. 몇 분 뒤 같은 화면 상단에 표시되는 주소(사용자명.github.io/레포명)로 접속합니다.

## iPhone에서 쓰기

1. Safari로 배포 주소를 엽니다.
2. 공유 버튼 → 홈 화면에 추가를 누릅니다.
3. 홈 화면 아이콘으로 실행하면 주소창 없이 전체 화면으로 열리고, 한 번 열어 둔 뒤에는 오프라인에서도 실행됩니다.

## 알아둘 제약

- 화면을 잠그거나 다른 앱으로 전환하면 iOS가 페이지 실행을 멈추므로 그동안 소리가 나지 않습니다. 돌아오면 실제 흐른 시간 위치로 복원됩니다. 운동 중에는 화면을 켜 둔 채 사용하세요.
- 화면 켜짐 유지는 Safari 16.4 이상에서 동작하고, 홈 화면 앱으로 쓸 때는 iOS 18.4 이상이 필요합니다. 설정 화면의 '화면 켜짐 유지' 항목에서 상태를 확인할 수 있습니다.
- iPhone 무음 모드에서는 비프음이 나지 않을 수 있어 '무음 모드에서도 소리' 설정을 두었습니다(기본 켜짐). 켜 두면 다른 앱 음악이 멈출 수 있으니 음악과 함께 쓸 때는 꺼서 비교해 보세요.
- 소리와 음성은 시작 버튼을 누를 때 활성화됩니다. 앱으로 돌아왔을 때 소리가 나지 않으면 화면을 한 번 탭하세요.
- 프리셋은 기기별 브라우저 저장소에 저장되므로 iPhone과 PC 사이에 공유되지 않습니다. Safari와 홈 화면 앱도 저장소가 분리될 수 있습니다.

## 수정 후 다시 배포할 때

- sw.js의 CACHE 이름에 있는 버전 문자열을 올려야 새 파일이 캐시에 반영됩니다.
- index.html의 APP_VERSION도 같은 값으로 올리면 설정 화면의 버전 표시로 반영 여부를 확인할 수 있습니다.
